# WebServe

C++14 / Linux HTTP server reproduction inspired by
[markparticle/WebServer](https://github.com/markparticle/WebServer).
See NOTICE and LICENSE for attribution.

The complete implementation is prepared and tested before a 46-day scheduled
publication. Each published commit represents a real subset of that prepared
implementation; publication dates do not represent daily development activity.
Early commits contain individual modules; the runnable server arrives after
the networking integration step. A final usage guide follows at completion.
